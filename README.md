# Yenway

Сайт для заказа вещей с зарубежных площадок (Япония, Корея, Китай, США, Европа).
Пользователь вставляет ссылку на товар → сайт показывает фото и считает стоимость
(товар + комиссия + страховка + доставка) → заявка с ником в Telegram сразу
прилетает вам в бота.

## Запуск локально

```bash
npm install
cp .env.example .env
npm run dev
```

Открыть http://localhost:3000

## Настройка Telegram-бота (5 минут)

1. Написать [@BotFather](https://t.me/BotFather) → `/newbot` → получить `TELEGRAM_BOT_TOKEN`.
2. Написать своему новому боту любое сообщение (например "старт").
3. Открыть в браузере `https://api.telegram.org/bot<TOKEN>/getUpdates` и найти
   `"chat":{"id":XXXXXXXX` — это `TELEGRAM_CHAT_ID`.
4. Вписать оба значения в `.env` (локально) и в переменные окружения хостинга (для продакшена).

## Курсы валют и тарифы

Всё в одном файле — `lib/pricing.ts`:

- `EXCHANGE_RATES` — курс валюты каждой площадки к рублю
- `DELIVERY_FLAT_RUB` — стоимость доставки по регионам
- `SERVICE_FEE_PERCENT`, `INSURANCE_PERCENT` — комиссия и страховка

Как пришлёте актуальные данные — просто обновим эти значения.

## Деплой с постоянным доменом (Vercel, бесплатно и без падений)

1. Залить проект в GitHub-репозиторий.
2. Зайти на [vercel.com](https://vercel.com) → New Project → выбрать репозиторий.
3. В настройках проекта → Environment Variables добавить `TELEGRAM_BOT_TOKEN` и
   `TELEGRAM_CHAT_ID`.
4. Deploy — сайт получит бесплатный домен `yenway.vercel.app`.
5. Свой домен: Project → Settings → Domains → добавить купленный домен (например
   `yenway.ru`) и прописать DNS-записи, которые покажет Vercel. После этого домен
   постоянный и не "слетит".

## Структура проекта

- `app/page.tsx` — главная страница с разделами по регионам
- `app/order/page.tsx` + `components/OrderForm.tsx` — форма заказа
- `app/api/order/route.ts` — приём ссылки, расчёт стоимости, отправка в Telegram
- `lib/og.ts` — получение фото/названия товара по ссылке
- `lib/pricing.ts` — курсы и тарифы (редактировать здесь)
- `lib/regions.ts` — список регионов и площадок
